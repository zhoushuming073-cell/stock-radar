# Box official-source route preflight — 2026-10-17

**Result: free SEC filing chronology has an observational CIK join for the complete Validation Dolt/raw candidate stratum, but does not itself certify the traded security or LEAN execution data.** This is a read-only source-feasibility check. No source was adopted or installed in the frozen Research Infrastructure v1.

The audit re-hashed all 1,748 candidate chunks against the independently verified full-Validation file-set SHA-256, then read only the 3,729 Dolt/raw candidate security/date keys. A read-only query of the frozen construction database required `issuer_evidence.available_on <= decision_date` and an active ticker episode at that date. Every candidate-day had exactly one observed CIK and one active episode. The 424 distinct internal security IDs map to 422 distinct observed CIKs; no internal ID changed observed CIK across these Validation candidate-days. This is **not** a one-to-one security-class map: more than one security ID may share an issuer CIK, and an observation may be stale, incompatible, or incomplete. The separate [full mirror-support audit](box-candidate-reference-full-2026-10-17.md) finds only 2,405/3,729 with a *recent compatible* CIK mirror under the frozen 31-day rule.

The [SEC EDGAR API documentation](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) offers free public filer submission histories with filing metadata and nightly bulk archives. Its `submissions` JSON includes current company metadata, so a current ticker/name field cannot be retroactively treated as a historical security-class binding. Any programmatic collection must follow [SEC fair-access and user-agent rules](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data). The [Nasdaq Trader public symbol lookup](https://www.nasdaqtrader.com/Trader.aspx?id=symbollookup) describes its lookup as current-day; its public event data are a subset of the historical [Daily List subscription product](https://beta.nasdaqtrader.com/Trader.aspx?id=DailyListPD). The subscription path was not used or ordered.

**Decision boundary:** the existing trust-catalog/master workflow can receive source-dated official issuer/class and corporate-action evidence, but the current 13-source catalog has zero exact-ID overlap with Dolt/raw Validation candidates. SEC filing chronology is a plausible free input for the 422 *observed issuer CIKs*; it cannot alone establish the exact traded class, exchange action chronology, accepted same-source execution prices or adjustment factors. Expanding the official evidence corpus and choosing a durable class/action source is a material data-source decision. This preflight neither promotes an observational CIK to a certified ID nor rebuilds frozen data.

The [aggregate receipt](../evidence/box-candidate-cik-route-2026-10-17.json) contains only counts and hashes; identities and candidate dates remain private. No future price values, outcomes, Test/Fresh data, orders or box LEAN portfolio backtest were read or run. No code changed; the latest full Native-inclusive pytest remains 818 passed, 8 skipped, one existing warning. Train candidate scanning continues independently.
