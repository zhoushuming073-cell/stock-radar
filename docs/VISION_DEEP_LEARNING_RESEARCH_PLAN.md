# Stock Radar — 纯视觉深度学习策略研究计划书

> **2026-10-08 历史路线迁移：** 本文件保留为纯视觉研究的历史基线与 P0/P1 基建合同。当时曾迁移到 Quant+Vision v1；该决定后来又被 v2/v3 与当前三路径总研究框架取代。现行分类见 [Research Master Guide](RESEARCH_MASTER_GUIDE.md)。旧 P0/P1 基建继续复用，历史验收不撤销。

> 版本：Plan v1.0 · 2026-10-08  
> 状态（历史验收）：**P0 IMPLEMENTED / PASS；P1 INFRASTRUCTURE PASS；RANDOM BLIND HUMAN LABELING RETIRED AS PRIMARY TASK。** PR [#5](https://github.com/zhoushuming073-cell/stock-radar/pull/5) 已通过六个真实本地门禁并合并 main（`8f20a8bb843801b3b9bd61fc5f8d2a9fd835a99d`）。标注基础设施就绪，不代表 Ground Truth、模型或云端视觉检验完成。  
> 主目标：通过历史 K 线图像与人的审美判断，训练一个能在未知历史时段自主识别潜在有利交易形态、给股票排序的视觉模型。  
> 边界：与现有规则型 Strategy 2 平行，不用规则分数充当视觉模型答案；不修改现有策略参数、数据库、LEAN 生产接口、QC smoke 或 PIT 门禁。

## 1. 为什么做这条路线

现有规则策略把“先涨得强、回撤、跌势衰竭、有承接、小幅转强、尚未明显拉升”等直觉翻译成固定阈值。纯视觉路线要回答一个不同的问题：

**能否让模型像研究者看 K 线一样，直接从历史蜡烛图与成交量图中学到较难手写的形态结构，并且在未来未见过的数据上持续找出更有潜力的候选？**

研究目标分为两层，必须分别检验：

1. **学会人的形态判断**：模型对同一批不显示未来走势的图，偏好和人工判断有多一致？
2. **人的偏好是否真的有交易价值**：模型挑出的图，在之后固定观察期内是否比当时同等可交易股票有更有利的收益与风险分布？

第一层成功不意味着第二层成功。不得把“模型模仿我”直接说成“策略盈利”。

## 2. 职责和最终流水线

研究者：看图、做少量高质量标注、比较难例、解释主观偏好并参与阶段评审。

Codex / 本地 Stock Radar：构造 PIT 意识明确的历史窗口、开发标注界面、训练与评估模型、版本管理、生成冻结候选信号。

QuantConnect Cloud / LEAN：后续用合规的方式验证冻结信号的组合执行；条件成熟时再评估云端加载冻结模型，直接使用 QC 自己历史行情重做完整视觉选股。不能把“QC 执行本地名单”称为“QC 独立验证了模型输入和股票池”。

流程：

**历史市场候选 → 截止 T 日收盘可见的 K 线图 → 人工盲评 → 视觉深度学习 → 冻结模型与候选名单 → 时间外检验 → 云端执行检验 → 决定保留/淘汰。**

初期完全可以本地训练和回测，**不以本地通用 PIT Tier 2 或购买 QC 付费资源为启动前提**；但只允许在明确、可审计的本地数据范围内提出探索性结论。

## 3. 输入定义：真正的“纯视觉”

### 3.1 模型输入

优先使用标准化的日 K 线图（蜡烛实体、上下影线）与成交量副图。不把手写的回撤百分比、均线距离、成交量收缩系数、Strategy 2 分数、公司代码、名称、新闻或基本面作为模型特征。

允许数据读取程序使用日期、证券身份、上市状态、价格口径等元数据来生成正确图像和研究样本；这些元数据**不是**模型的预测输入。

同一组 OHLCV 数据可以生成标准化数值窗口供绘图和审计，但“纯视觉模型”的预测路径必须来自图像。以后若试验 OHLCV 时序模型或 Quant+Vision 融合，必须作为**另一个独立实验**标记，不能冒充纯视觉。

### 3.2 决策时点与窗口

默认研究 **T 日收盘后** 做判断，T+1 日开盘才可能买入。图中最大日期为 T，绝不包含 T+1 的开盘、高低价、收盘或之后发生的事件。

优先做 60 与 126 个交易日窗口；20、40 个交易日作为后续对照。使用相同图片尺寸、时间轴排列、纵轴处理、K 线宽度、颜色、成交量布局。记录绘图器版本、价格口径和原始窗口哈希。

对股票分拆应保持历史当时可见的连续图形：仅使用 **截至 T 已生效且当时可知** 的拆股信息进行一致处理，不许使用 T 之后的拆股、当前 ticker 或日后修订身份去重绘 T 的输入。复权模式和交易执行价格必须分别声明，绝不混接。

首版图中不显示：未来 K 线、之后收益、当前公司状态、股票名称/代码、预测标签；研究者先盲评，之后可以通过独立界面揭示真相用于复盘。不得通过文件名、像素边框、样本顺序泄漏未来结果。

## 4. 数据底座与幸存者偏差

沿用已存在的历史数据库和未来 Shape Research Layer，但每个样本必须携带：

- 历史 security ID、历史 ticker 及有效日期区间；
- 信号日期 T、窗口首末日期、来源与价格口径；
- 当时 membership 的 confirmed / probable / unknown 状态；
- identity/split/价格冲突状态、数据缺口和窗口哈希；
- 数据集版本、绘图器版本、标签版本、时间分区。

训练总体**不能由今天仍上市的股票名单倒推**。历史上后来退市、被收购、破产或消失的股票，只要当时有可信 K 线和可交易资格，就应进入候选总体；缺价或身份可疑者明确排除或隔离，并报告排除率、年份分布、流动性分布、已退市样本覆盖率。

本地整库截至 2026-10-08 仍为 **Tier 1 Exploratory PIT**。报告中的 79.9471% 行情可用性是已观察普通股候选 member-days 的限定口径，**不代表美国市场有 80% 完整可信历史数据**。视觉研究必须先单独量出可用窗口数和可靠程度，不得据全库有价格就默认训练集没有偏差。

不能用 QC Cloud 的参考数据、历史行情或可重建它们的明细导出来补本地训练集；遵守当前平台条款与已触发的导出警告。

## 5. 人工标注：先教它认形态，而非先教它追收益

首版建立一个快速、可撤销、可复核的浏览器标注界面。每次只出现一张历史截断图，或同时出现两张图做成对选择。

**单图标注**：很喜欢 / 一般 / 不喜欢 / 看不懂。另可选记录“下跌未停”“承接明显”“拉升已过”“疑似形态异常”等简短主观理由，但理由不是模型的硬编码训练特征。

**双图盲选**：A 更值得继续观察 / B 更值得继续观察 / 都不好 / 难判断。成对偏好是优先研究信号，因为它比要求人精确给 0—100 分更自然。

标注前不能显示未来走势、标签、历史盈亏或代码；允许跳过，不强迫给出答案。抽取样本时既覆盖典型好图，也覆盖假企稳、连续破位、暴涨后反抽、低流动性干扰、不同市场阶段等难例，不能只拿 Strategy 2 已选的股票让人评价。

首轮建议收集约 **200—300 张单图判断 + 100—150 组成对比较**作为小规模试点，数字是工作量建议、不是模型验收门槛。少量重复图用于测量自身判断的一致性；对难判断图允许保留“不确定”。

标注采取“先人工 → 模型提出疑难样本 → 人工再判断”的主动学习路线。模型可以提示“最拿不准的几张”，但不能把预测结果先展示给标注者形成暗示。

**标注者的职责是定义喜欢什么样的图，真实收益标签必须由独立、固定的未来评价规则计算。两者不能互相冒充。**

## 6. 标签与未来结果必须分开

建立两套完全独立的标签：

**A. 主观视觉标签**：人工喜好、成对选择、置信度、标注者、标注时间和标注版本。

**B. 客观事后结果**：例如 T+1 开盘开始、未来 5/10 个交易日是否曾达到 +5%/+8%/+10%，最大有利/不利波动、破新低频率、实际止盈/止损的先后顺序和费用后结果。具体目标、执行规则及 intraday 价格不可见时的歧义处理必须提前冻结，不得因回测好坏临时改变。

B 只能用于训练期的独立辅助学习或事后评价；绝不作为 A 的“正确答案”，也绝不进入 T 时点的图片、文件名、排序提示或抽样名单中。

建议先训练模型模仿 A 的偏好，再检验高评分是否对应更好的 B；只有独立样本稳定显示有益时才考虑多任务目标。**避免一开始就把“事后涨幅大”当成“人应该喜欢的图”。**

## 7. 深度学习技术路线

按难度从低到高推进，不先买显卡、不先上超大模型：

**M0：无训练基准**。随机排序、历史可交易股票基准以及简单固定基线，证明后来模型确有增益。

**M1：小型图像网络**。先用小型 CNN / ResNet-18 量级视觉编码器做单图分类和成对排序；先判断能否复现人工偏好。记录数据量、算力、训练稳定性、置信区间，避免小样本训练出伪精度。

**M2：主动学习**。把模型最不确定、与人判断冲突或易混淆的图返回人工标注；定期检查模型是不是只学会了“跌得越猛越好”“价格越低越好”“图越平滑越好”等投机性捷径。

**M3：更强视觉结构**。只有 M1 在完全未用作调参的时期稳定有价值，才尝试轻量 ViT、自监督视觉表征或较大模型。始终保留可复现的 M1 基准，并在单独实验里对比。

模型主要输出 **视觉适合度分数/排序及不确定性**，而不是直接承诺收益率。若后来增加未来收益概率预测，必须独立校准并清楚标注其目标。

禁止为了追逐历史收益，把模型、图片尺寸、颜色主题、时间窗口、损失函数和止盈止损无限试到“好看”为止。每次实验均保存完整版本与试验次数。

## 8. 训练、验证与 OOS 纪律

按时间先后划分 Train、Validation、Historical Test、Fresh OOS，不按随机图像切分；同一证券相邻日期产生的高度相似窗口不能被随机打散成训练/考试两边。用户已提前看过的历史测试阶段，不得宣称是全新的盲测。

优先沿用仓库冻结的研究阶段边界并复核是否适用于视觉标签与预测窗口；确保完整未来评价窗没有穿越分区，不满足则设置 purge/embargo 或放弃边界样本。历史输入窗口可以包含当时已发生的过去，不能把真正已知的历史重用误判成未来泄漏。

分别保留：

- **Train**：学习人工偏好/可选的历史目标。
- **Validation**：选模型版本、早停、有限调参。
- **Historical Test**：锁定版本后的少次数历史检验，已看过的切片只称历史测试。
- **Fresh OOS**：在模型冻结后新积累的数据；不标注回流训练、不调模型、不反复试到过关。

增加按股票/发行主体划分的留出诊断，测试模型是否记住个股图形；按年份、波动环境、流动性、已退市身份等分组报告表现。所有用于比较的样本池、排名上限、候选冷却期、成本和观察周期预先固定。

## 9. 我们如何判断视觉路线值得继续

验收不能只看分类准确率，更不能只看一张漂亮的资金曲线。分四层：

1. **人工一致性**：重复盲评的自洽程度，成对偏好是否稳定，多少样本属于不可判断。
2. **模型学人**：人机偏好一致率、成对排序正确率、不同年份和股票上的稳定性、校准与不确定性。
3. **选股增量**：在历史当日可交易股票总体中，Top 5 / Top 10 / Top 20 的 Precision、Lift、MFE/MAE、假企稳率，相比随机/基础方法是否有增量。
4. **实际交易**：固定执行假设下的费用后收益、最大回撤、成交与仓位容量、交易次数、年度分解和强弱行情表现；只有这一层才谈组合可行性。

阈值须在查看正式测试结果前冻结。重点要看增量是否跨年份稳健，是否被少数行情或股票撑起，以及剔除污染和可疑数据后是否依然成立。没有增量就暂停或终止，不因训练投入而继续追加复杂度。

## 10. QuantConnect Cloud 如何接入

**阶段一：冻结信号执行验证**。视觉模型在本地对可追溯的历史股票池生成“日期、当时证券身份、分数、排名、目标交易信号”，连同模型/数据/绘图版本和哈希冻结。QC Cloud 只按这些信号执行组合，检验交易和公司行动处理。这一步**不验证视觉模型的本地训练总体是否存在幸存者偏差**。

**阶段二：完整外部验证（未来选项）**。当模型稳定、QC 算力与文件/模型存储权限可满足、且已核对平台条款时，上传获许可的冻结模型或预测程序；让 QC 在其自己的历史 Universe 与行情上生成同规格视觉窗口并推理、排序和执行。必须核对图片一致性、当时身份和价格口径，才可称为完整独立视觉回测。

不得声称免费 QC Cloud 一定能加载大型视觉模型；不能为了绕过限制批量导出 QC 原始数据、股票池或派生重建材料。用户未授权前不购买付费资源。

## 12. 人与 Codex 的分工

研究者只需要做三类高价值决策：选定初版图样、盲评图或图对、最后判断“这种形态筛选是否值得继续”。

Codex 负责所有重复性工程：候选抽样、绘图和复现、网页标注工具、数据体检、泄漏检查、试验版本、模型训练、统计验证、结果整理、问题回溯。

遇到输入数据不足或污染，先列明受影响区间、人数/股票数和替代方案；不要擅自放宽规则、删除失败股票或将未知状态当成不存在。

## 13. 风险清单

- **学会人但不赚钱**：主观偏好与真实事后收益分开评测。
- **只会挑幸存股票**：用当日历史候选集合，量化已退市样本覆盖与未覆盖风险。
- **未来信息泄漏**：输入截止 T、事件/拆股按 T 生效、T+1 执行、严格时间外分区。
- **记住个股而非形态**：去标识化图片、时序隔离、股票留出诊断、难例抽样。
- **过拟合 QC/Test**：云端成绩和 Fresh OOS 不用于反复调参；记录全部试验次数。
- **把交易结果当数据质量证明**：固定信号云回测不替代完整模型独立检验。
- **训练样本过少**：先小规模人机一致性基线，再决定扩大标注或模型。
- **模型/数据泄露**：历史行情、标注原文、训练样本图、权重和密钥默认存本地受忽略目录；GitHub 只放源码、接口、汇总报告、合法可分享的示例与校验哈希，除非另获用户授权。

## 15. 最终成功定义

**不是模型在训练集识别出几张好看的 K 线，不是一次云回测盈利，也不是让人工规则换个深度学习名字。**

成功是：一个只看历史当时可见 K 线与成交量图的冻结模型，在未来没见过的股票与市场时段中，持续选出比同一时点可交易基准更有利的候选；其提升经得起数据污染检查、交易成本、年度切片和最终独立验证。如果做不到，应有清楚可复查的否证结论。

**当前决定：保留规则 Strategy 2；视觉基础设施继续复用，但主路线迁移到 Quant-guided Human Labeling → Vision → Quant+Vision Fusion。随机盲图人工审美不再是当前下一步。**
