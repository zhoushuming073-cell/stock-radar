# 股票量化研究：文献目录与阅读顺序

整理日期：2026-10-09。按你的要求继续使用 `论文阅读包-2026-10-08` 文件夹。

当前共 **17 份 PDF，对应 16 篇不同论文**。本次新增 8 份 PDF；此前已有的 3 份英文 PDF 和你放入“参考文献”的 6 份中文 PDF 均保留原文件。A03 正式发表版与 A03-WP 工作论文是同一篇研究，去重时只算 1 篇。

已核对 PDF 文件头、页数、首页题名和尾页，并渲染首页检查可读性。页数为 PDF 实际页数，可能包括封面、附录和仓储说明页。期刊信息指论文最终发表去向；标注为工作论文或预印本的本地文件不等同于正式发表版。

## 建议先读这 6 篇

顺序按 stock-radar 的日线形态扫描、Quant/Vision/Fusion 比较和样本外验证方向安排；下面的问题是阅读建议，不是对策略收益的保证。

1. **A01：价格图像与趋势识别。** 关注价格图的构造、预测标签、时间切分和样本外检验，先理解视觉模型与股票筛选的连接方式。
2. **A02：技术形态自动识别。** 关注如何把人工看到的形态写成可重复的算法，以及如何比较形态出现前后的收益分布。
3. **C01：技术交易检验。** 关注交易成本、规则是否持续有效，以及尝试许多规则后如何处理假发现。
4. **A03：机器学习资产定价，优先读正式发表版。** 关注不同模型是否使用相同数据、预测目标和样本外区间；再思考 Quant、Vision、Fusion 的公平比较。
5. **A05：新因子的增量价值。** 关注新增评分或信号是否在已有因子之外提供信息，避免只靠单独回测表现判断价值。
6. **C02：回测过拟合概率。** 关注反复筛选参数与策略带来的选择偏差，作为研究流程和最终回测的检查项。

中文补充可先读 B01（浙大多因子选股），再读 B02（上财联邦因子模型）。D01、D02 用于补充序列模型和树模型比较。A04、A06 可在熟悉基础检验后深入阅读。

本轮新增全文集中在此前列出的论文；温州大学作者的相关论文尚未补入本地包。中文文献中，B01 来自浙江大学、B02 来自上海财经大学，B03–B06 来自杭州电子科技大学等机构。

文件目录“01-高水平高校”“03-策略检验与回测”“04-机器学习与图像策略”沿用整理结构；你的中文原文件继续放在“参考文献”。“02-补充院校”目前为空，没有为了填目录而复制相同论文。

## 研读时可统一记录

| 记录项 | 可以关注的问题 |
|---|---|
| 数据与股票池 | 是否含退市股票？历史股票池如何确定？是否处理复权？ |
| 标签与输入 | 标签是否只用未来结果？输入是否含未来信息？图像如何标准化？ |
| 训练与验证 | 是否按时间划分？滚动训练和参数选择是否与最终测试隔离？ |
| 基准与增量价值 | 是否与买入持有、简单动量/反转及现有因子比较？ |
| 交易执行 | 何时产生信号，何时成交？是否考虑成本、滑点、换手率？ |
| 研究可靠性 | 是否多次选参数？是否进行多重检验和稳健性检验？ |
| 对 stock-radar 的启发 | 能否用于候选筛选、标签设计或 Quant/Vision/Fusion 比较？ |
